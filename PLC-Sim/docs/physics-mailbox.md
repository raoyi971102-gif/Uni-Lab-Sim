# 跨Python进程的确认屏障

`FilePhysicsPort` 在私有共享目录发出唯一请求，由Isaac主线程的 `PhysicsMailboxWorker.serve_once()` 消费。请求带world/session/epoch/tick/dt，回执携带实际物理步确认及采样。只有CoupledSession校验全部身份和时间后提交逻辑时间。

邮箱由单一调用者和单一工作进程独占，不是公开网络API。容器只挂载选定私有目录，不挂载真实设备凭据。消息最大2 MiB；图像应传另行封存的帧引用或摘要，不把无限数据塞入控制通路。

超时不重发、不假定未执行，必须保留pending并冻结会话。工作进程在调用物理SDK之前登记started；重启看到started而无回执时返回不确定，不重复执行。新会话物理复位须显式发出更高epoch；进程故障保护不等于整机掉电事务保证。

等待上限是墙钟预算，不是仿真dt。首次渲染可能编译着色器，验收入口显式记录等待上限；超过上限仍严格失败，不改变物理步长。正常往返、超时、错误epoch和未确认请求的进程重启拒绝均由回归测试覆盖。
